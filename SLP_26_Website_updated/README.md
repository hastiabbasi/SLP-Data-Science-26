# TensorFlowed Spaceship Titanic Showcase

An interactive Streamlit website for the TensorFlowed team’s Spaceship Titanic project.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Then upload `train.csv` and `test.csv` in the sidebar. You can also upload a model-comparison CSV and final submission CSV to activate the Model Arena and Submission Center pages.

## Demo recording flow

1. Open Mission Control and introduce the project.
2. Move to Data Explorer and explain two charts.
3. Open Model Arena and explain the model comparison.
4. Open Submission Center and discuss the final score and submission.
5. Use Voiceover Guide as the narration outline.

The app is designed to support a 5–7 minute walkthrough, but sections can be shortened for the final presentation video.
